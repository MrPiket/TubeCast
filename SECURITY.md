# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly via [GitHub's private vulnerability reporting](https://github.com/MrPiket/TubeCast/security/advisories/new) instead of opening a public issue.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

## Scope

TubeCast is designed for self-hosted use. Security concerns include:
- Input validation (YouTube URLs, video IDs)
- Path traversal or command injection via user input
- Denial of service through resource exhaustion
